# Sistema Financeiro Home Money 🏦

Projeto de validação de transações financeiras e testes automatizados desenvolvido em Python.

## 🛠️ Tecnologias Utilizadas
* Python 3
* Pytest (Testes Automatizados)
* VS Code

## 📌 Funcionalidades
* Processamento e validação de saques com tratamento de exceções (`try/except`).
* Suíte de testes automatizados para prevenção de dados inválidos de entrada.

## 🚀 Como Rodar o Projeto
1. Clone o repositório.
2. Instale as dependências: `pip install pytest`
3. Execute os testes: `pytest`
