# 🤖 Home Money Bot - Assistente & Sistema Bancário em Python

Projeto focado no desenvolvimento de um sistema bancário interativo com persistência de dados em SQLite e rotinas automatizadas em Python.

## 🛠️ Tecnologias Utilizadas

* **Python 3** (Lógica de programação e automação)
* **SQLite / Banco de Dados** (Persistência e registro de logs/atendimentos)
* **Git & GitHub** (Versionamento e controle de código)

## 📌 Funcionalidades Principais

* **Validação e Operações de Caixa:** Validação de transações, saques e depósitos.
* **Persistência em Banco de Dados:** Armazenamento seguro de históricos e registros em banco de dados (`.db`).
* **Consulta de Logs:** Script focado em visualização e auditoria de registros (`ver_logs.py`).
* **Integração:** Estrutura modular preparada para automações e agentes inteligentes.
